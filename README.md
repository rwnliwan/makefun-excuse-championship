Entry for [The One-Line Excuse Championship](https://make.fun/bounty/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun — one line, the excuse an AI agent gives its human after something goes wrong. The program writes the entry to `/output/entry.txt`.

## Entry

> Your file was garbage, so I collected it.

41 characters, one line, one sentence. The machine is not dodging the question: it reports its own work. The garbage collector did exactly its job — the file was classified as garbage, so it was collected. The turn lands in the last three words.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). Writes `/output/entry.txt`.
